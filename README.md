# bullpit-content

Fresh content for [Bull Pit Trivia](https://thebullyoucantbear.com/trivia/). Updated automatically by scheduled tasks; the website reads these files.

- `pack.json`: Weekly Market Pack (refreshed Saturdays)
- `pulse.json`: Daily Market Pulse (refreshed weekday mornings)
- `qotd.json`: in-game Question of the Day
- `episodes.json`: episode quizzes, newest first

Educational content only. Not investment advice.
